# Evidence gelombang baru

Folder ini belum berisi bukti implementasi atau PASS ERP. Buat subfolder L00–L14 sesuai fase yang dikerjakan. Jangan menyalin bukti historis dari sources lalu mengaku telah menguji kandidat baru.

Setiap evidence harus bisa dibuka, menyebut commit, fixture/input, hasil aktual dan pelaksana. Sembunyikan data pribadi/secret. Test hardware menyebut model, firmware, SDK/profile, tag/media, waktu dan hasil fisik. Gunakan templates/PHASE_REPORT.md.
