# RF03 — Adapter gate UR300 dan passage

**Kebutuhan:** RFID-05, RFID-06  
**Dependensi:** RF01, P02, P03

## Pekerjaan

- [ ] Pasang service sesuai runtime PoC, dengan autostart/recovery, kontrol inventory dan port/antenna profile.
- [ ] Petakan arah dan logical gate. Jika reader menangani dua arah, definisikan source tepercaya per antena/sensor; payload antenna saja belum mengubah direction API existing.
- [ ] Kalibrasi zona baca, tag diam/berdekatan, kendaraan/troli, beberapa roll, reverse/re-entry dan passage boundary.
- [ ] Gunakan keputusan ERP berdasarkan movement/manifest; red-dominant, unknown/stale/offline mempunyai SOP yang disepakati. Jangan menganggap EPC yang tidak terbaca pasti tidak ada.
- [ ] Kendali indikator mengikuti passage valid saat ini; backlog/duplicate/error tidak memberi green baru. Pengakuan alarm tetap berotorisasi.

## Acceptance

RACC-02, RACC-10, RACC-11, RACC-12, RACC-13, RACC-15. Baca [matriks acceptance](../ACCEPTANCE_RFID.md).

**Gate:** Reader, EPC, konteks dokumen, arah, alarm dan recovery terbukti di instalasi nyata; data gate tidak auto-post qty stok.
