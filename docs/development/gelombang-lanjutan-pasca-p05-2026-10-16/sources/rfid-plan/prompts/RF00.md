# RF00 — PoC perangkat dan pemetaan SDK

**Kebutuhan:** RFID-01, RFID-11  
**Dependensi:** P00

## Pekerjaan

- [ ] Inventaris kedua unit, firmware/OS, module RFID, SDK/license dan cara instalasi aplikasi.
- [ ] Cocokkan nama UR300 dengan label/datasheet; dokumentasi publik resmi yang ditemukan bernama U300. Jangan mengganti model diam-diam.
- [ ] Jalankan demo SDK pada unit, uji trigger/EPC/RSSI, antena, jaringan dan GPIO/indikator bila digunakan.
- [ ] Putuskan runtime adapter gate dari bukti unit: on-device Android atau service edge. C72 app berada pada handheld.
- [ ] Rebase kondisi API repo terbaru dan identifikasi source/read path existing yang berupa simulasi/DB.
- [ ] Inventaris CP30EN aktual, firmware/modul RFID/resolusi/koneksi/media dan SDK; cocokkan profil keluarga CP30.
- [ ] Cetak-encode satu label dari payload ERP dan baca chip memakai C72; uji kegagalan encode serta media calibration dengan dokumentasi model.

## Acceptance

RACC-01, RACC-02, RACC-21. Baca [matriks acceptance](../ACCEPTANCE_RFID.md).

**Gate:** PoC menghasilkan profil hardware dan kontrak SDK yang konkret; compatible tidak dinyatakan dari brosur saja.
