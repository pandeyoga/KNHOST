# P06 — Special Order multi-produk dan jalur desain pelanggan

**Kebutuhan:** IMP-07, IMP-08  
**Dependensi:** P04, P05  
**Ukuran relatif:** XL  
**Status awal:** not_started

## Tujuan

Mendukung pesanan khusus multi-produk dengan penerimaan desain, R&D, dan dokumen lanjutan per baris.

## Pekerjaan server dan kontrak

- [ ] Gunakan ID line OD stabil dan source article/design version. Tetapkan transisi design ready, needs adjustment, proofing, approval, pricing, procurement, dan SO per line.
- [ ] Desain pelanggan yang diterima dapat melewati pembuatan desain, tetapi tidak melewati persetujuan kesiapan/proofing yang diwajibkan.
- [ ] Pertahankan hubungan OD line ke request R&D, SKU/spec, supply, dan SO line. Header merangkum seluruh line, bukan hanya line pertama.
- [ ] Dukung pembatalan/revisi/parsial menurut kebijakan; retry pembuatan dokumen tidak menggandakan SKU, PR, atau SO.

## Pekerjaan antarmuka

- [ ] Form multi-produk dengan source article, warna/spec, desain, qty/unit, tenggat, dan progres per line.
- [ ] Detail menampilkan versi desain, siapa menyetujui, tindakan selanjutnya, dan chain dokumen tiap produk.
- [ ] Hak pembuat/pengelola OD mengikuti keputusan PIC; jangan menetapkan Admin Sales sebagai owner otomatis.

## Data lama dan migrasi

- [ ] OD single-product lama dimigrasikan/adaptasi menjadi satu line dengan ID stabil dan hubungan dokumen tetap.
- [ ] Missing source/version historis ditandai unknown, bukan diisi ACC palsu. Uji pembacaan oleh consumer lama sebelum penulisan model baru diaktifkan.
