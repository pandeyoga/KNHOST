# P09 — Fingerprint langsung, log mentah, perhitungan shift, dan monitoring HR

**Kebutuhan:** IMP-30, IMP-31, IMP-32, IMP-33, IMP-34, IMP-35  
**Dependensi:** P00, P01  
**Ukuran relatif:** XL; hardware-dependent  
**Status awal:** not_started

## Tujuan

Membuktikan mesin nyata dapat mengirim ke ERP langsung, lalu menyediakan pemrosesan kehadiran yang dapat ditelusuri.

## Pekerjaan server dan kontrak

- [ ] P09-A dimulai setelah P00: pilih calon terminal time attendance dan firmware, peroleh dokumentasi protokol, uji custom server dan kiriman nyata sebelum membuat receiver generik.
- [ ] P09-B setelah P01 dan PoC: receiver/adaptor berjalan di server ERP dengan registrasi perangkat, respons protokol, penyimpanan durable, batch parsing, dan retry.
- [ ] Mapping device/enrollment ke employee/entity/site eksplisit. Unmapped/ambiguous event disimpan untuk review; tidak ditebak dari nomor enrollment saja.
- [ ] Pisahkan raw event immutable, hasil normalisasi, agregat shift, koreksi HR, dan data yang disahkan untuk payroll. Simpan waktu perangkat/diterima serta metadata sumber.
- [ ] Deduplikasi sesuai event identity protokol; jangan membuang dua punch sah yang kebetulan berbagi timestamp. Tangani offline backfill, out-of-order, clock drift, dan kegagalan parsial.
- [ ] Lindungi jalur perangkat sesuai kemampuan model: enrollment/serial bukan bukti otorisasi tunggal; gunakan verifikasi dan pengamanan koneksi yang layak. Jika butuh jalur aman khusus, konfirmasi desain jaringan tanpa memaksakan laptop/gateway lokal.

## Pekerjaan antarmuka

- [ ] Pengaturan mesin dengan model/firmware/lokasi/status dan mapping pegawai.
- [ ] Monitoring last_contact terpisah dari last_successful_ingest, backlog jika dapat diketahui, error, unmapped, audit koreksi, dan reprocess.
- [ ] Kehadiran menampilkan sumber log dan shift, bukan hanya hasil jam masuk/pulang tanpa bukti.

## Data lama dan migrasi

- [ ] Import CSV/bridge existing tetap mempunyai jalur transisi; label sumber dibedakan dari native-device events.
- [ ] Data attendance historis yang hanya agregat tidak dibuatkan punch asli fiktif. Tandai evidence unavailable.
- [ ] Aktivasi per perangkat/pilot dahulu; pemrosesan payroll mengikuti otorisasi HR/Finance yang disepakati. Template fingerprint tidak dibutuhkan di ERP.
