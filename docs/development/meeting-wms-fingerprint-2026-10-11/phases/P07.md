# P07 — Jenis sampel dan proses Admin Cutting

**Kebutuhan:** IMP-09, IMP-10  
**Dependensi:** P02, P04  
**Ukuran relatif:** L  
**Status awal:** not_started

## Tujuan

Menyediakan tiga jenis sampel dan handoff pemotongan sampai pengiriman tanpa konsumsi stok ganda.

## Pekerjaan server dan kontrak

- [ ] Gunakan sample type Hanger/Katalog/Cutting yang berbeda dari pricing scheme dan R&D test.
- [ ] Tambahkan transisi cut_requested, cut_actual, handed_to_admin, final_processing, ready_to_dispatch, dispatched atau padanan state existing yang semantik sama.
- [ ] Catat hasil aktual dan serah terima. Pengurangan roll sumber terjadi pada event konsumsi yang sah satu kali; handoff bukan goods receipt baru.
- [ ] Terapkan permissions/PIC, rules qty/biaya/persetujuan, pembatalan, dan selisih hasil sesuai keputusan klien.

## Pekerjaan antarmuka

- [ ] Pilihan tiga jenis sampel pada Sales, status setelah potong, antrean Admin Cutting, bukti handoff, dan aksi proses akhir/kirim.
- [ ] Gudang tidak menandai terkirim hanya karena selesai potong. Tampilkan ukuran hasil serta sisa roll sumber.

## Data lama dan migrasi

- [ ] Petakan sample type lama dengan bukti dan gunakan skrip migrasi existing bila tepat; daftar yang ambigu ditinjau.
- [ ] Dokumen historis yang benar-benar sudah dikirim tidak dibuka kembali karena alur baru. Open sample dimigrasikan menurut posisi fisik/pekerjaan aktual.
