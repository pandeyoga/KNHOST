### Contoh angka (U3) — dokumen → jurnal → buku pembantu

Faktur `VB/PK18/…` PT KSC: neto 10.000.000 + PPN 1.100.000 = **11.100.000**, `amount_paid` 0. Setujui saat akun 2-1100
PT itu nonaktif → `gl_status="failed"`, 0 jurnal. Akun diaktifkan → Ulang Posting:

| Akun | Debit | Kredit | Hitungan |
|---|---:|---:|---|
| 2-1150 GR/IR | 10.000.000 | | grand total − PPN = 11.100.000 − 1.100.000 |
| 1-1500 PPN Masukan | 1.100.000 | | `ppn_amount` |
| 2-1100 Hutang Usaha | | 11.100.000 | grand total |

Saldo 2-1100 PT KSC (normal kredit) naik 11.100.000 = sisa hutang faktur 11.100.000 − 0. Ulang kedua → 404; tetap 1 jurnal.
