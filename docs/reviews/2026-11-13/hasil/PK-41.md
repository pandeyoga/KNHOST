### Contoh angka — dokumen → jurnal → buku pembantu (hitung tangan)

- **U1** (PT uji, termin 30): pesanan 100.000; surat jalan SJ-U1 1 Sep → jurnal `shipment_revenue` **Dr 1-1200 40.000 /
  Cr 4-1000 40.000** (`ref.order_id`). Per 15 Nov: baris SJ-U1 nilai 40.000, terbayar 0, sisa 40.000, jatuh tempo
  1 Sep + 30 = **1 Okt**, lewat 15 Nov − 1 Okt = **45 hari** → kolom 31–60; belum dikirim 100.000 − 40.000 − 0 = **60.000**
  → belum jatuh tempo. Piutang tercatat 40.000 = saldo 1-1200 PT 40.000 → selisih **0** (U15). Status kredit: lewat tempo
  40.000, telat 45 hari (U3; dulu 100.000).
- **U7** (Oktober): kas awal 1.000 − 100 = **900**. Jual tunai Dr 1-1100 300 / Cr 4-1000 300 → operasi +300; sewa Dr 6-2000
  50 / Cr 1-1100 50 → operasi −50; `fixed_asset_disposal` Dr 1-1100 130, Dr 1-2900 20 / Cr 1-2100 100, Cr 4-9100 50 →
  investasi **+130** (baris 1-2100, laba 50 tidak ke operasi); `interco_loan` Dr 1-1100 500 / Cr 2-1250 500 → pendanaan
  **+500**; `bank_opening_balance` Dr 1-1100 200 / Cr 3-2900 200 → saldo awal **200**. Kas awal disesuaikan 900 + 200 =
  **1.100**; perubahan 250 + 130 + 500 = **880**; kas akhir 1.100 + 880 = **1.980** = saldo 1-1100 (900 + 300 − 50 + 130 +
  500 + 200).
- **U10**: tagihan VB-U10 Cr 2-1100 100.000 (jatuh tempo +20 hari → belum jatuh tempo 100.000); retur beli `ap_basis`
  hutang **Dr 2-1100 20.000** / Cr 1-1300 (nota debit belum dipotong kontrabon mana pun); biaya masuk diterapkan Dr 1-1300
  / **Cr 2-1100 10.000** (voucher belum dibayar). Pencocokan 100.000 + 10.000 − 20.000 = **90.000** = saldo 2-1100
  (100.000 − 20.000 + 10.000) → tidak terjelaskan **0**.
- **U11**: surat jalan Dr 1-1200 / Cr 4-1000 100.000, HPP Dr 5-1000 / Cr 1-1300 60.000 (biaya roll 6.000 × 10); nota kredit
  retur Dr 4-1000 20.000 / Cr 1-1200 20.000 + barang kembali Dr 1-1300 / Cr 5-1000 12.000; hapus buku Dr 5-9500 / Cr 1-1300
  12.000. Layar: pendapatan 100.000 − 20.000 = **80.000**, HPP 60.000 − 12.000 = **48.000**, marjin **32.000**,
  32.000 / 80.000 = **40,0 %**. Laba-Rugi: pendapatan 80.000, beban pokok 5-1000 48.000 + 5-9500 12.000 = 60.000, laba
  kotor **20.000** = 32.000 − 12.000 (beban pokok selain HPP) + 0 (antar-PT) + 0 (selisih).

1. `label_kelompok_umur` mengembalikan hanya kolom yang bisa terisi `_bucket`: batas < 3 → kolom ketiga tidak ada (spesifikasi

## Asumsi

- `ASUMSI:` (spesifikasi) pembayaran mengurangi baris berjatuh tempo tertua; kelebihannya uang muka atas bagian belum dikirim.
- `ASUMSI:` (spesifikasi) pemberi pinjaman antar-PT = investasi, peminjam = pendanaan — ditentukan dari jenis akun lawan
  kas (kewajiban → pendanaan, aset → investasi).
- `ASUMSI:` (spesifikasi, `00` §4.1) tagihan tanpa `due_date` diisi tanggal tagihan + termin pemasok; pemasok tanpa termin
  = 0 hari (perilaku ringkasan lama).
- `ASUMSI:` `debit_notes_open` = Σ (debit − kredit) akun hutang (`pembelian.hutang`) jurnal `purchase_return`/
  `purchase_return_reversal` per retur − Σ potongan retur itu di kontrabon berstatus `paid` (kontrabon lunas = potongan
  menjadi pelunasan non-kas faktur, `contra_bon_service`). Tanpa field penanda baru.
- `ASUMSI:` surat jalan yang jurnal pendapatannya gagal/belum terbit dihitung "belum dikirim" sampai jurnalnya terbit
  (piutang tercatat = buku besar).
- `ASUMSI:` `difference` = saldo akun piutang − piutang tercatat (positif = buku besar lebih besar).
