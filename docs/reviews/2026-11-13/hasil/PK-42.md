## UX-05 — Tombol buat mati dengan alasan tertulis saat "Semua PT"

- Berlaku di HEAD: ya (11 tombol); 2 tombol antar-PT tidak (rutenya tingkat grup).
- Akar masalah: pagar server baru menolak sesudah form diisi; tombol di layar tidak membaca mode PT.
- Perubahan perilaku: komponen baru `components/EntityGatedButton.jsx` (+ `EntityGateNote`). `selectedEntity === "all"` →
  `disabled`, `aria-disabled`, `title` = "Pilih satu PT dulu (kanan atas) untuk {what}.", dan alasan pendek **tertulis
  di samping tombol** ("Pilih satu PT dulu", `{testid}-scope-hint`). Kepala kartu yang sudah padat (Jurnal: 5 tab + 3
  tombol; Aset Tetap: judul, jumlah, cari, 2 tombol) memakai `hint={false}` + bilah sendiri `EntityGateNote` di atas isi
  kartu dengan kalimat lengkap. Dipasang di 11 tombol (tabel spesifikasi, minus antar-PT); label tombol tidak berubah.
  `BudgetView` tombol berkelas Tailwind sendiri → `primary-button`.
- Berkas: `components/EntityGatedButton.jsx` (baru), `styles/components.css` (`.entity-gated*`), 11 layar di tabel.
- Pengujian: U1–U3 (jest), rute 409 (B).

## UX-12 — Daftar berhalaman dengan jumlah total

- Server: `GET /api/ar-receipts` urut `created_at` (lalu `id`) menurun **di kueri**; `page`/`page_size` → amplop
  `{items,total,page,page_size,has_more}`, `q` = `number`/`customer_name`; tanpa halaman: larik, batas 2.000 sesudah
  urut. `GET /api/cash-transactions`: halaman opsional, `q` = `number`/`description`/`category`, urut
  `txn_date`/`created_at`/`id` menurun; tanpa halaman: seperti dulu. `GET /api/cash-transactions/summary` + `counts:
  {all, kas_kecil, kas_besar}` (non-anulir, cakupan daftar — `_cash_list_query` dipakai bersama daftar).
- Layar: `ARReceiptsHistory.jsx` → `usePagedList("/ar-receipts", {pageSize: 25, params: {entity_id}, search})` +
  `PaginationBar label="penerimaan"`; `CashManagementView.jsx` → `usePagedList("/cash-transactions", {pageSize: 50,
  params: {entity_id, cash_type}, search})`, `useListSearch` dicabut, lencana tab dari `summary.counts`,
  `PaginationBar label="transaksi"`, kosong "Belum ada transaksi kas.".
- Unduh baku (KN_37 §6, penjaga G-UI-07 dan INV-UI-07): kedua pager memasang `exportSpec` (dataset `ar_receipts` /
  `cash_transactions`) + `exportConfig` (CSV kolom-layar); registry dataset ditambah `search_fields` yang sama dengan `q`
  endpoint (tanpa itu Pusat Export menolak 422 bila kotak cari terisi).
