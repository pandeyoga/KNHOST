## IV-02 — roll scrap tetap bernilai sesudah dihapus-buku

- Berlaku di HEAD: ya (U1 merah: roll `damaged` 80 m × 12.000 tetap bernilai 960.000; 1-1300 turun 960.000 → selisih
  rekonsiliasi bergeser 960.000).
- Akar masalah: jurnal hapus-buku mengeluarkan nilai dari 1-1300, tetapi roll `damaged` (status yang dinilai rekonsiliasi)
  tetap membawa biayanya.
- Perubahan: `release_quarantine` — roll scrap yang jurnal hapus-bukunya ada (baru/sudah ada) menyimpan
  `writeoff_unit_cost`/`writeoff_base_unit_cost` dan `unit_cost = base_unit_cost = 0` di tulisan roll yang sama; riwayat biaya
  `scrap_writeoff`. `reverse_writeoff` memulihkan kedua biaya dari field simpanan (riwayat `scrap_writeoff_reversal`); roll scrap
  lama tanpa field simpanan tidak diubah biayanya (memang tidak pernah dinolkan). Data lama: skrip migrasi (H3).

## IV-06 — retur beli mengeluarkan persediaan sebesar nilai nota, bukan nilai buku roll

## IV-07 — HPP surat jalan jatuh ke rata-rata bila ada roll berbiaya 0

### Contoh angka U3 — dokumen → jurnal → buku pembantu

Roll `r` 50 m, `base_unit_cost` 10.000, `unit_cost` 10.500 (nilai buku 50 × 10.500 = **525.000**). PO ber-PPN 11 % dengan faktur
`posted` → retur mendebit hutang. Retur beli 50 m @ 10.000: nota 500.000 + PPN 55.000 = **555.000**; selisih 525.000 − 500.000 =
**25.000**; kunci `retur.selisih_retur_beli` → 5-9910 (fixture).

| Akun | Debit | Kredit | Hitungan |
|---|---:|---:|---|
| 2-1100 Hutang usaha | 555.000 | | nilai nota termasuk PPN (`grand_total`) |
| 5-9910 Selisih nilai retur beli | 25.000 | | nilai buku − nota tanpa PPN |
| 1-1300 Persediaan | | 525.000 | nilai buku roll yang keluar |
| 1-1500 PPN masukan | | 55.000 | PPN nota |

Σ debit 580.000 = Σ kredit 580.000. Hutang PO berkurang 555.000 (`returned_amount`). Subledger persediaan turun 525.000 (roll →
`returned_supplier`) = kredit 1-1300 → `difference` tidak bergeser (kode lama: kredit 500.000, 25.000 tertinggal di 1-1300 tanpa
roll). Tanpa pemetaan (U4) jurnal lama tetap dan `book_value_diff` 25.000 tampil di rincian retur.

### Contoh angka U10 — retur jual dinilai pada biaya saat dijual

Pesanan kredit 200 m @ 20.000 (4.000.000, tanpa PPN). Satu surat jalan: `r1` 100 m × 10.000 + `r2` 100 m × 14.000 → HPP Dr 5-1000 /
Cr 1-1300 **2.400.000** (potret). Roll lain produk itu 100 m × 16.000 → rata-rata produk kini 16.000. Retur `r2` 100 m kondisi
baik, selesai "refund" (bawaan: memotong sisa tagihan SO asal lebih dulu, LN-091):

| Akun | Debit | Kredit | Hitungan |
|---|---:|---:|---|
| 4-1000 Pendapatan | 2.000.000 | | 100 × 20.000 |
| 1-1200 Piutang | | 2.000.000 | pengurang piutang SO asal |
| 1-1300 Persediaan | 1.400.000 | | 100 × 14.000 (potret `r2`) |
| 5-1000 HPP | | 1.400.000 | |

Roll `r2` kembali karantina ber-`unit_cost` 14.000 → subledger +1.400.000 = debit 1-1300 → `difference` tetap. HPP neto pesanan
2.400.000 − 1.400.000 = 1.000.000 = biaya `r1` yang tetap di pelanggan. Kode lama: 1.600.000 di keduanya (selisih tetap, tetapi HPP
neto 800.000 dan `r2` dinilai 200.000 di atas biayanya).
