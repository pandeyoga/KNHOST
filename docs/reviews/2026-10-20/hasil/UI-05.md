## FE-10 — Antrean QC salah label satuan dan agregasi campuran
- **Berlaku di HEAD:** ya — `quarantine_qty` = jumlah `length_remaining` roll karantina tanpa satuan; layar
  memberi label "m" dan menjumlahkan semua tugas. Data acuan: roll hanya **yard (30.684)** dan **kg (15.823)**,
  tidak ada meter — label "m" selalu salah.
- **Perubahan perilaku:**
  - Backend `GET /inbound/qc/queue` menambah per tugas: `quarantine_unit` (satuan roll karantina; cadangan
    satuan tugas), `quarantine_by_unit` (rincian per satuan), `quarantine_unit_mixed`. **Tanpa konversi.**
  - Layar: total "Total di Karantina" per satuan (mis. "130 yard · 40,5 kg"), baris & form keputusan memakai
    satuan tugas ("Diterima (kg)"), catatan untuk tugas non-yard bahwa interval inspeksi 4-Point di mesin
    tetap yard dan tidak dikonversi; roll bersatuan campuran → rincian + keputusan satu angka diblokir.
  - Modal 4-Point per roll (interval yard) tidak diubah.
- **Bukti:** pytest `test_fe10_qc_queue_units.py` (fixture 3 tugas: yard, kg, campuran — dibersihkan): satuan &
  rincian benar, campuran tidak diberi satuan tunggal; **gagal di kode lama**. Jest: total per satuan, tanpa "m",
  form tugas kg berlabel kg + catatan interval. Regresi 8 berkas QC/karantina: tidak ada gagal baru.
- **Status:** implemented_pending_review

## FE-11 — Error awal penerimaan transfer tertutup loading
- **Berlaku di HEAD:** ya — `if (!data) return Memuat…` sebelum `ErrorNotice`.
- **Perubahan perilaku:** status muat dipisah dari error aksi (scan/terima). GET pertama gagal → kartu
  "Penerimaan transfer <kode> belum bisa dimuat" + pesan server + **Coba lagi**; retry berhasil → panel
  normal. Gagal muat ulang saat data sudah ada → data tetap, error + Coba lagi tampil.
- **Bukti:** jest — 403 pertama: tidak ada "Memuat…", pesan & kode transfer tampil; Coba lagi → panel tampil.
  **Gagal di kode lama.**
- **Status:** implemented_pending_review

## FE-12 — Neraca unknown ditampilkan Seimbang
- **Berlaku di HEAD:** ya — `balanced !== false`.
- **Perubahan perilaku:** hanya `true` = "Seimbang" (hijau); `false` = "Tidak Seimbang" (merah); memuat =
  "Memuat…", undefined/null = "Belum diketahui" (netral). Muat neraca gagal → data periode sebelumnya
  dikosongkan (sebelumnya angka & lencana periode lama tetap tampil untuk periode yang gagal).
- **Bukti:** jest — true/false/undefined/null/loading. **Gagal di kode lama.** Browser (Manager): Neraca data
  acuan → `state=ok`, "Seimbang".
- **Status:** implemented_pending_review
