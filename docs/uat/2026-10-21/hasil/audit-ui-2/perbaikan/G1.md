## Risiko

- `interco_service.list_accounts` kini menghitung ulang angka saldo dari dokumen terbuka setiap GET (satu kueri agregat
  seluruh dokumen seller terbuka) — ringan untuk volume sekarang; cache tidak ditulis di GET (gate INV-IC-04 tetap bisa
  mendeteksi cache basi).
- `consolidation_service.sync_g6_ic_eliminations` kini juga memperbarui entri bila judul/catatan berbeda → sinkron
  pertama sesudah rilis melaporkan "N diperbarui" untuk semua entri G-6 lama (sekali saja).
- `gl_summary` menambah 2 kueri (`count void`, `distinct source_type`) per muat Buku Besar.
- Sapuan `apiErrorText`: untuk galat ber-status tanpa `detail` (mis. 500/404 kosong) kalimat kini dari peta status
  bersama, bukan kalimat cadangan per layar. `isForbiddenError` (bedakan 403 vs daftar kosong) belum dipasang per layar.
- Tombol "Catat tagihan supplier" (G1-24) memakai tautan `?view=vendor-bills&po=…`; layar Tagihan Supplier belum membaca
  param `po` (hanya membuka layarnya).
- Anulir kas turunan dokumen lain kini nonaktif di layar (server memang menolak 409); bila ada kas turunan lama tanpa
  `ref_type`, perilaku server tidak berubah.
