## 11. Risiko
1. Sampai backend di-restart, katalog lama masih berlaku: Admin Sales/Admin Gudang tanpa grup Pengaturan, peran kustom belum
   mendapat id baru, antrean design_gallery masih ke alias Galeri (ACC) — **jangan UAT sebelum restart**.
2. `settings-hub`/`akuntansi`/`analytics` di modul domain memperlebar `view_resources` id grup → grup TERBUKA bagi peran bawaan
   yang rancangan menunya memang memuatnya (Admin Sales, Admin Gudang) — itu tujuannya; menu per item tetap disaring `roles`/ROLE_NAV.
3. `price-corrections` di modul Produk (bukan Harga seperti tulisan §6) — sesuai izin server.
4. Peran kustom bermodul SDM/Operasi Gudang kini melihat Pengaturan › Integrasi & Sistem (hanya tab Perangkat).
5. `?view=my-approvals` untuk sales mendarat di tab sah miliknya (Pengajuan Harga Khusus) — perilaku resolver P1, sama dengan `approvals`.
