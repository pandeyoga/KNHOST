## Perubahan perilaku (sebelum → sesudah)
1. **SSOT baru** `customer_service.due_context(orders)` + `order_due(customer, order, ctx)`:
   * dasar = tanggal **Surat Jalan pertama** (SJ aktif tertua) — satu agregasi per daftar;
   * lama termin = snapshot SO (`payment_term_days`) → **kode termin SO** (Syarat Bayar, lapisan PT menang atas global;
     CBD 0, NET30 30, DP50 14, …) → profil pelanggan → 30;
   * SO tanpa SJ → **belum jatuh tempo** (`None`).
2. Dipakai di semua penghitung: status kredit pelanggan (*telat* hanya untuk SO ber-SJ), **daftar tagih / antrean
   Meja Finance "Jatuh tempo" / pengingat penagihan** (SO belum dikirim tidak masuk), **Umur Piutang** (SO belum
   dikirim di kolom *belum jatuh tempo*, tanpa estimasi denda; rincian per pesanan menulis **"belum dikirim"** +
   `due_basis`), pengingat H-x (`orders_due_soon`), Tanya KN (piutang/telat), **Proyeksi Kas** (SO belum dikirim =
   perkiraan paling cepat "kirim hari ini + termin", ditandai *perkiraan · belum dikirim*, tidak pernah "lewat").
3. Total piutang/eksposur tidak berubah — hanya tanggal jatuh tempo, keterlambatan, dan keanggotaan daftar tagih.

Berkas: `backend/services/customer_service.py`, `services/ar_aging_service.py`, `services/ai_tools.py`,
`services/cashflow_forecast_service.py`; frontend `features/finance/ARAgingView.jsx`,
