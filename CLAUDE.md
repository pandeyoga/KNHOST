## Khusus Claude Code
* Peran di repo ini: **implementer** temuan review. Sebelum mengerjakan temuan, baca
  `docs/reviews/README.md` (protokol) dan `docs/reviews/TRACKER.md` (status terkini).
* Setiap fase selesai → tulis `docs/reviews/<tanggal>/hasil/<FASE>.md` memakai templat di
  protokol, perbarui baris tracker (status, "Berlaku di HEAD", commit, tautan laporan).
* Jangan pernah menetapkan status `verified` atau `reopened`.
